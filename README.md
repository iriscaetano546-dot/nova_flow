## 💻 Sobre o projeto

<!-- EXPLICA O MOTIVO DO PROJETO -->
Esse projeto foi desenvolvido no curso de Tailwind, como objetivo aplicar os conceitos do framework na construção de uma interface responsiva, limpa e funcional.

Embora não possua funcionalidades dinâmicas ou integração com back-end, a NovaFlow apresenta um layout que simula uma solução real de gerenciamento de projetos, com seções pensadas para facilitar a visualização de tarefas, progresso e colaboração entre equipes.
